# Edge cases and recovery

| Event                                      | Behavior                                                                                                                                                                                        |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Worker suspends between checks             | Alarms wake it; settings and archive stay in local storage. In-memory queue need not survive.                                                                                                   |
| Alarm lost after restart/update            | Worker initialization checks and recreates the alarm; startup registers checks.                                                                                                                 |
| Chrome <121                                | Session-local activity tracking, conservatively initialized to now when native activity is unavailable. Browser restart restarts fallback ages.                                                 |
| Tab IDs reused on restart                  | Operation journals include a random storage.session session token. Old IDs are never used to infer live matches.                                                                                |
| Group recreated/reopened                   | Exact title + color protection applies without relying on ephemeral ID.                                                                                                                         |
| Group renamed/recolored                    | In-session binding adds the new signature while preserving old protection. If worker misses that event during an exceptional crash, old signature still exists; verify renamed groups in popup. |
| Duplicate names/colors                     | Protect all matching groups. Use distinct names/colors to choose independently.                                                                                                                 |
| Group/window closed manually               | Retain protection rule; manual closures are not normally added to the archive.                                                                                                                  |
| Source window gone during restoration      | Use another normal window or create one. Original window IDs are used only in the same browser session and only if still present.                                                               |
| Restore grouped entries                    | Create ordinary groups per original window/group within that restore operation. A later separate restore can create another group. No stale group IDs are reused.                               |
| Beforeunload cancellation                  | Recheck tab existence after removal settles. Live tabs do not become confirmed archive entries.                                                                                                 |
| Crash after archive write, before close    | Journal recovery never initiates another close; unresolved cases are retained conservatively.                                                                                                   |
| Restart during pending close               | Keep an uncertain archive entry, with an explicit warning before user restores.                                                                                                                 |
| Crash during restore                       | Persist create intent, then returned tab ID. Same-session confirmed live URL finalizes restoration; uncertain outcomes stay archived and are not retried automatically.                         |
| Disk write failure                         | Stop before any next destructive operation. Existing persisted pending intent survives, though the current UI may need extension reload after storage recovers. Toolbar badge shows `!`.        |
| URL fails to load after create             | A browser tab was successfully restored to that URL. Network/login/page errors are handled by Chrome, not treated as an API create failure.                                                     |
| Audio begins or tab becomes active         | Re-read tab state just before closing. Chrome offers no atomic compare-and-close operation; a very small unavoidable race remains.                                                              |
| Form edited and then saved                 | Keep open until reload/navigation; the extension cannot reliably observe every app’s save operation.                                                                                            |
| Existing page lacks document-start guard   | Skip. User can reload if appropriate; extension does not reload pages.                                                                                                                          |
| Discarded or frozen                        | Skip rather than waking page or claiming to know whether data was saved.                                                                                                                        |
| Host permission denied/iframe inaccessible | Skip entire tab.                                                                                                                                                                                |
| Automatic archive above 50 candidates      | Process up to 50 successes per check; later alarms handle remaining candidates.                                                                                                                 |

Journals intentionally prefer retaining a duplicate recoverable URL over losing it. Uncertain entries can be restored by an explicit user action; the UI warns to check open tabs first. Exact-once browser tab creation across process termination cannot be guaranteed because Chrome offers no transactional idempotency key for tabs.create.
